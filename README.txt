ЗАБРОШКИ АГИНСКОГО — сайт-архив

Запуск:
1. Распакуй архив.
2. Открой index.html в браузере.

Заметки и добавленные референсы сохраняются локально в браузере на этом устройстве
(localStorage). Для публикации сайта загрузи папку на GitHub Pages, Netlify или другой
статический хостинг.

Файлы:
- index.html — структура сайта
- style.css — оформление и анимации
- script.js — заметки, сохранение, добавление референсов
- assets/ — предоставленные изображения

Анимация появления заголовка стилизована под рисование маркером; интерфейс адаптирован
для телефонов. Сайт не содержит карты или точных маршрутов к заброшенным объектам.
